LINE Relay Bridge｜LINE 訊息橋

使用你的帳號讀取一般群組。群組名稱直接選取，支援表情符號。

1. 登入 LINE

請使用登入此帳號的那台 iPhone。LINE → 主頁 → 設定 → 我的帳號：開啟「允許自其他裝置登入」，並完成 Face ID／Touch ID 連結。這次登入可能使原本的電腦版 LINE 登出。

尚未登入

PIN 出現後，請在 iPhone LINE → 主頁 → 設定 → 我的帳號 →「連動其他裝置」輸入，再完成 Face ID／Touch ID 認證。請於 3 分鐘內完成，不需等待簡訊或聊天訊息。若未顯示輸入畫面，重新啟動手機 LINE 後再試。登入資料保存於 %LOCALAPPDATA%\LineCallYomiProbe；請勿分享此資料夾。

2. 選擇一般群組

3. 驗證文字收訊

可用另一個帳號在所選群組發一則測試文字，再確認這裡是否出現。頁面保留本次讀到的訊息，按匯出可保存。最近 50 則輪詢可能漏掉大量訊息，尚非正式轉送服務。LINE 社群（OpenChat）不在本次支援範圍。
