如何取得讀取及發送權限？

將 Bot 加入來源及目的群組；來源 Bot 需有管理員權限或關閉 Privacy Mode。個人目的需先向 Bot 按 Start。此模式讀取 Bot 收到的訊息，私人帳號的其他對話不會自動出現。

請使用未設定 webhook、未被其他程式輪詢的專用 Bot。Token 僅保存於本機，頁面不會回傳保存的 Token。選用 DPAPI 後只能在原 Windows 使用者下解密；之後重新連結仍維持保護。原有明文檔保留供復原，LINE 登入及訊息尚未加密。換電腦時請重新輸入 Token。

載入僅查看 Bot 尚未確認的更新，不顯示訊息內容。不在清單的聊天室可手動輸入 ID；頻道通常以 -100 開頭。LINE 社群尚未支援。

尚未連結

在 Discord Developer Portal 建立 Bot，透過 OAuth2 的 bot 範圍加入伺服器，授予查看頻道及發送訊息權限。開啟 Discord 開發者模式後，右鍵頻道複製 ID。不可使用個人 Token 或 Webhook。純目的不需 Message Content Intent；權限檢查不發訊。

DPAPI 只保護本次保存的 Token；舊明文檔若存在仍保留。換電腦／Windows 帳號需重新連結。

進階設定：指定發訊者、內容與時段
勾選要加入的人員

每個來源分別設定。使用固定 ID；改名不影響。LINE 優先列已加入成員；Telegram 只列最近發訊者。勾選後按「加入選取人員」，固定 ID 留空代表所有人。

跨午夜以開始日計算。略過依訊息時間；保留依實際發送時刻。修改規則只影響新入列訊息，已待送內容不重新篩選。

預設關閉；圖片最多 10 MB、檔案最多 50 MB（十進位）、說明含前綴最多 1,024 字元。LINE 只收 JPEG／PNG 圖片；圖片先送、說明另送。LINE 檔案保留待送並暫停該配對。任何發送結果不明都不自動重送，請核對圖片及說明。LINE 圖片不支援回覆關聯。無法確認大小或格式時暫停該路線。模擬可檢查圖片／檔案大小、說明、指定人員與時段；不讀取真實附件。

只引用同一路線已確認送達的原訊息；原訊息被篩除或人工處理時，改送一般訊息。LINE 引用失敗會暫停，不自動重送。

設定備份、還原與安全診斷
設定備份不含登入與 Bot Token，但包含聊天室 ID、名稱、關鍵字及前綴，請私下保存。還原僅替換規則，不還原去重／待送進度；原設定會先另存本機。
安全診斷只有版本、狀態與計數，不含憑證、訊息、聊天室 ID／名稱及錯誤全文。
容量監控與私人封存
封存包含訊息、聊天室與去重／待送證據，不能分享；不含登入憑證，不能替代完整私人備份。保留原檔，不會釋放空間。此版本不自動刪除紀錄。
手動更新：停止轉送、關閉程式、私下備份完整資料目錄，再解壓新版至另一個目錄。不要把新版待送資料交給舊版。
