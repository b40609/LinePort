## 早期版本限制（v0.3.0 已擴充）

- 未完成多日負載、強制斷電、所有 LINE 登入錯誤與上游協定變動測試。

- 安全稽核當時未重啟真實轉送服務；下載更新的使用者需依 [更新步驟](../docs/USAGE.md) 重啟後才套用新程式。

## v0.3.0 多規則與 Telegram 驗證（2026-10-08）

- `npm test`：61 項全部通過；新增多來源／目的、關鍵字、規則循環阻擋、同名 ID、重啟去重、發送不明跨重啟暫停、來源退避與目的故障隔離驗證。
- LINE 群組／好友列舉與前頁補讀採模擬資料；包含游標不前進與上限拒絕。Telegram 採合成 Token 與模擬 HTTPS 回應，驗證純文字發送、目的 ID 與有效回應 ID、保護內容及錯誤遮蔽。
- Telegram offset 在寫入並同步成功後才推進；測試涵蓋重新載入、損壞末行、寫入失敗後不再確認更新。
- 使用獨立 18767 模擬服務，透過瀏覽器操作恢復登入、群組與好友載入、Bot 聊天室載入、一來源三目的、篩選與前綴、啟停鎖定、編輯回填及暫停／啟用。
- 預覽 `<script>` 文字按純文字呈現；瀏覽器無 JavaScript 或 CSP 錯誤。Token 輸入欄位保存後清空。
- 本版開發未重啟真實轉送，不讀取真實登入憑證，不對 LINE 或 Telegram 發送測試訊息。
- 新增 LINE 好友、多配對與 Telegram 尚未做真人跨平台收送、朋友端或多日負載驗證。歷史補讀有 1,000 則上限，Telegram 本機選定來源文字上限 50,000 則；沒有完整送達保證。
- 舊單配對紀錄不自動遷移；升級需重新建立規則並測試新文字。詳見 [更新步驟](../docs/USAGE.md#更新)。
