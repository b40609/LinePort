# 驗證紀錄（2026-10-08）

## 已完成的真實使用驗證

- iPhone 授權登入、恢復工作階段、一般群組列表及文字解密成功。
- 已完成一則文字傳送後讀回，核對目的訊息 ID 與文字。

## 此次安全修正驗證

- `npm test`：23 項測試全部通過，包含同批去重、首次基準、損壞紀錄拒絕啟動、發送結果不明停止、上游逾時辨識，以及本機 HTTP 權限、CSP、輸入限制與並行操作。
- 模擬測試不登入 LINE、不讀取真實憑證，也不向真實群組發送測試文字。
- Windows ACL 在獨立假資料目錄驗證通過；PowerShell 語法解析通過。
- npm 及 .NET 已知依賴漏洞查詢均為 0；這不是無漏洞保證。
- 詳細修正與剩餘風險見 [SECURITY.md](../SECURITY.md)。

## 尚未驗證／尚未支援

- 未完成多日負載、強制斷電、所有 LINE 登入錯誤與上游協定變動測試。
- OpenChat、Telegram、多來源、完整歷史補抓及全文封存未支援。
- 只有最近 50 則視窗；首次基準、停機、發送不明與高流量都可能漏訊。
- 安全稽核當時未重啟真實轉送服務；下載更新的使用者需依 [更新步驟](../docs/USAGE.md) 重啟後才套用新程式。

- `npm test`：35 項全部通過；新增加密準備檢查、讀取診斷、固定錯誤訊息、介面警示、Windows 啟動器與 ACL 重入驗證。
