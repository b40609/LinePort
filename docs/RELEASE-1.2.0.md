# LinePort v1.2.0 更新說明

本版本包含完整的媒體與附件轉送修復、長期穩定與維運優化、防無聲死亡機制（自 v1.1.0 併入），以及全新的 C3 品牌圖示。

## 圖片與檔案附件（媒體轉送）
- 修正 LINE E2EE 圖片／檔案解密後的 JSON（內含 `keyMaterial` 與檔名）被誤當成純文字轉送的問題；關閉附件轉送的規則不再送出 JSON 字串。
- 補齊 LINE 來源圖片／檔案、LINE 目的檔案、Telegram 來源與目的附件、Discord 目的附件的記憶體內安全下載與上傳（含檔案大小驗證與不明結果保護）。

## 轉送韌性與防無聲死亡
- 新增**單筆隔離（Soft DLQ）**：平台明確拒絕單一訊息（如 Telegram／Discord 413 或訊息本身格式 400、附件超限）時，僅略過並記錄審計日誌，不阻塞後續轉送；連續 4 則明確失敗仍保守暫停路線，結果不明的發送一律不隔離。
- 新增**積壓快轉審核**：人工處理不明發送時，可選擇「確認收到，補送後續積壓」或「確認收到，快轉到現在（略過舊訊並寫入審計紀錄）」。
- 新增**停止後安全壓縮紀錄**（`compaction.mjs`）：先建立並通過 SHA-256 驗證的私人封存，再以語意核對後的精簡紀錄逐檔原子取代，保留完整去重、待送、不明發送、回覆對照與最近 500 則原文。
- 新增**LINE 自適應輪詢**與**跨來源內容去重（選用）**，降低空轉並減少多群轉發重複訊息。
- 整合 **v1.1.0 防無聲死亡機制**：Telegram 系統健康告警與恢復通知、確定未連線的網路錯誤退避重試、Windows 原生 Toast 通知、開機自動啟動防降級鎖與看門狗排程（`LinePort-Service-Recovery`）、升級自動清理過舊版本目錄。

## 桌面體驗與品牌識別
- 全面換裝 **C3 品牌圖示**（啟動器 `LinePort.exe`、桌面／開始功能表捷徑、Inno Setup 安裝程式與網頁 Favicon）。
- 升級**系統匣動態狀態燈**（C3 底圖 ＋ 綠／黃／紅／灰狀態燈點）與優雅關機端點、跨版本升級提示。
- 設定與診斷頁新增**手動「檢查新版」**按鈕（按下時才向 GitHub 查一次最新正式版，不自動下載或安裝，且僅連回本 repo 發行頁）。

## 安全評估結論
- 本版完成 SQLite WAL 與 LINE 憑證 DPAPI 加密可行性評估（詳見 `docs/DATA-RETENTION.md`），因風險與雙程序共用限制，本版維持現有 JSONL 與 DACL 保護架構，不進行不可逆格式遷移。

## 更新與安裝方式
- **安裝版**：下載 `LinePort-v1.2.0-Windows-x64-Setup.exe`，核對 `SHA256SUMS.txt` 後執行安裝，再從桌面 `LinePort` 捷徑啟動（會自動平滑切換可辨識的舊服務，保留既有登入與規則）。
- **免安裝版**：下載 `LinePort-v1.2.0-Windows-x64.zip`，完整解壓到新資料夾後雙擊 `LinePort.exe`。
- 更新後請核對帳號連結、規則狀態並按「開始轉送」。
