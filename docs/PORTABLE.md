# LinePort Windows 安裝版與免安裝版（先讀我）

目前版本：**v1.2.0**（內建 Node.js 與 .NET Windows Desktop 執行環境，支援 Windows 11 x64，不需另行安裝開發工具）。

## 安裝與啟動方式

### 方式 A：安裝版（`Setup.exe`）
1. 核對 `SHA256SUMS.txt` 後執行 `LinePort-v1.2.0-Windows-x64-Setup.exe`（免系統管理員權限，安裝於目前使用者目錄）。
2. 由桌面或開始功能表的 **LinePort** 捷徑啟動；每次升級安裝於獨立版本子目錄，自動保留舊版本、登入憑證、規則與轉送紀錄，並阻擋可辨識的降版覆寫。

### 方式 B：免安裝版（`Windows-x64.zip`）
1. 將下載的 ZIP **完整解壓縮**到新資料夾（勿在壓縮檔內直接執行，也勿只單獨搬移 `LinePort.exe`）。
2. 雙擊 **`LinePort.exe`**，啟動器會拉起本機背景服務（`127.0.0.1:18765`）、常駐右下角系統匣狀態燈並開啟設定頁面。
3. 更新時解壓新版到新資料夾並雙擊新版 `LinePort.exe`，啟動器會安全停止可辨識的舊版服務並切換至新版。

## 重要運作條件與注意事項

- **需要登入 Windows 工作階段**：自動啟動捷徑與看門狗排程（`LinePort-Service-Recovery`）皆在目前 Windows 使用者登入後運作；電腦重開機後若停留在登入畫面尚未登入，轉送不會啟動。
- **LINE 身分選擇**：同一台電腦若需同時開啟官方 Windows 電腦版 LINE，請在「1. 連結帳號」切換為 `iPad QR（IOSIPAD）` 身分；首次預設為 `DESKTOPMAC`。
- **更新與重啟安全**：辨識到不明占用程序、正在手機授權或新套件檔案不完整時，啟動器會顯示提示並中止，不會強制關閉非本程式的 Node.js 行程。EXE 尚未簽署程式碼簽章憑證。
- **已知限制**：詳細功能變更與尚未實機驗證之項目請見同目錄的 `更新說明.md`（`docs/RELEASE-1.2.0.md`）與 `SECURITY.md`。
