# LinePort Windows 免安裝版

1. 將下載的 Windows ZIP **全部解壓縮**到新資料夾。不要在壓縮檔內直接執行，也不要只搬走 EXE。
2. 雙擊 **LinePort.exe**，等待瀏覽器開啟；不需要安裝 Node.js、.NET 或輸入指令。
3. 新安裝依序連結帳號、設定規則、開始轉送；既有使用者確認原登入身分及規則後，按「開始轉送」。

更新時直接解壓新版到新資料夾、雙擊新版 LinePort.exe。啟動器會辨識舊服務、停止舊轉送並切換新版；保留原登入身分、登入資料、規則及轉送紀錄，不會要求 LINE 登出。更新後不會自動發送訊息，請在新版頁面確認並按「開始轉送」。

辨識不明程序、正在登入授權、無法安全停止轉送或新下載不完整時，啟動器會顯示錯誤並中止，不會任意關閉其他 Node.js 程式。請保留錯誤畫面供排查。

支援 Windows 11 x64。這是內含 Node.js、依賴套件及 .NET 執行環境的可攜資料夾，EXE 是啟動入口，整個資料夾必須保留。首次解壓較慢屬正常情況；EXE 尚未簽署數位憑證。
