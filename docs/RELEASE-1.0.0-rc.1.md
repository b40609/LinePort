## 使用方式

將 Windows ZIP **全部解壓縮到新資料夾**，雙擊 **LinePort.exe**。內含 Node.js、固定依賴與 .NET，不需要開發工具；不要只複製 EXE。支援 Windows 11 x64，尚未簽署數位憑證。

更新時會辨識舊服務的程序、路徑與版本，先停止舊轉送再切換新版，保留相同身分的登入、規則與轉送紀錄；更新後請自行按「開始轉送」。手機授權或其他操作進行中會拒絕換版。無法辨識的服務、降版或不完整套件也會中止；錯誤處理與限制見[免安裝說明](PORTABLE.md)。

## 為何提供 iPad 身分

原有 `DESKTOPMAC` 是 LinePort 對 LINE 宣告的桌面協定身分，即使主機是 Windows 也一樣；曾造成同帳號官方電腦版登出。`IOSIPAD` 使用另一類追加裝置及 QR 授權，已由單一帳號確認登入、恢復與官方 Windows LINE 同時收發，不能保證所有帳號／裝置均共存。

一般介面保留原有桌面授權與 iPad QR 實驗兩個入口；不依主機或手機品牌替使用者決定。需要官方電腦版共存可測試 iPad QR；需要保留官方 iPad LINE 則尚無已驗證方案。未實測的 `DESKTOPWIN` 不列為一般選項。[完整相容性說明](COMPATIBILITY.md)

## 朋友端驗收

使用專用測試聊天室與合成文字，記錄結果即可，不回傳帳號、QR、PIN 或登入資料。

1. 完整解壓並雙擊 EXE，頁面版本顯示 **v1.0.0-rc.1**。
2. 連結帳號、確認規則、開始轉送，等待初始化完成後傳新文字；每個目的實際收到一次。
3. 停止轉送並完整關閉 LinePort 程序（或重新啟動 Windows），再雙擊 EXE；身分、登入及規則保留。按開始轉送後，新文字可送達，已成功的舊文字不重送。只關閉瀏覽器分頁不算完整關閉服務。
4. 測試期間同帳號官方電腦版 LINE 持續登入，仍能正常收發。

尚未取得本候選版上述實機結果；自動化檢查使用隔離資料與替身服務，不能代替真實 LINE 收送、多日運作或其他裝置組合的驗證。
