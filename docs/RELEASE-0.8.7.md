# v0.8.7：雙擊啟動與自動切換舊服務

[下載 Windows 免安裝版](https://github.com/b40609/LinePort/releases/download/v0.8.7/LinePort-v0.8.7-Windows-x64.zip) · [SHA-256](https://github.com/b40609/LinePort/releases/download/v0.8.7/SHA256SUMS.txt)

將 ZIP 全部解壓縮，雙擊 **LinePort.exe**。已內含 Node.js、依賴套件與 .NET 執行環境，不需要安裝開發工具或輸入 PowerShell 指令。

更新者直接解壓新版並雙擊 EXE，啟動器會驗證舊服務的程序、來源與版本，自動停止舊轉送、關閉舊設定服務並開啟新版。保留原有登入身分與使用者資料；更新後按「開始轉送」即可繼續。進行中的發送依既有不明狀態保護，不自動重送。

新套件不完整、舊服務無法辨識或轉送無法停止時中止更新，不任意關閉其他程序；阻擋降版。若正在手機授權，請完成後再開啟新版。免安裝版支援 Windows 11 x64，需保留整個解壓資料夾，EXE 尚未簽署。

同時包含 v0.8.6 的 QR 登入保存、多代金鑰及群組加密修正。合成測試不能替代朋友帳號的實際 LINE 收送驗證。

驗證：免安裝套件在僅提供內附 Node.js 的 PATH 下，255 項測試全部通過；EXE 套件完整性檢查、啟動腳本派送及內附 runtime 路徑檢查通過。換版測試涵蓋跨資料夾更新、停止失敗保留舊介面、拒絕不相關程序及降版。
