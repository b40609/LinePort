# LinePort v1.1.0 更新說明

- 新增系統健康告警：路線暫停（含發送結果不明）、LINE 登入失效、來源連續讀取失敗或儲存容量達 80% 預警／停機時，以既有的 Telegram Bot 發送去識別化摘要通知，並在全部恢復正常時補發恢復通知；介面頁支援設定與「發送測試告警」。
- 改善 Telegram 網路錯誤分類：DNS 失敗、拒絕連線、連線逾時與 TLS 憑證錯誤確定未建立連線時，改採退避重試（5 秒起倍增，最長 5 分鐘），不再直接把路線永久鎖死成結果不明。
- 修正 Windows 本機通知改用原生 Toast（留在系統通知中心），避免舊版氣球通知過早消失。
- 強化開機自動啟動：加入 `schemaVersion` 與 `writtenByVersion` 防舊版降級覆寫鎖、服務啟動時自動修復舊版腳本、依版本號挑選安裝版啟動器，以及保留最近 200 行的 `autostart.log`。
- 新增本機看門狗排程（`LinePort-Service-Recovery`，登入時與每 5 分鐘巡檢）與安裝程式整合：尊重使用者手動停止意圖、15 分鐘最多自動重啟 3 次，觸發斷路器停手時記錄 `watchdog.log` 並跳出 Windows 通知。
- 安裝程式升級完成後自動清理過舊版本目錄（保留目前與上一個完整版本，不影響使用者設定與轉送紀錄）。

更新後，請由桌面 LinePort 捷徑啟動新版，確認帳號已連結、規則正常並開始轉送；建議到「設定與診斷 → 系統健康告警」填入告警聊天室 ID 並測試告警。
