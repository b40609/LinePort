# LINE／Telegram 分析師 Call 訊設定

目前需求是 2–3 個 LINE／Telegram 來源，送到合計約 3–4 個 LINE／Telegram 目的群組，Call 以文字為主、少量圖片。每個來源群各建一條規則，比較容易核對人員與關鍵字。每個來源都會送到該規則的全部目的，各配對有獨立待送與故障狀態。v0.7.1 選取時直接顯示配對數與附件支援範圍。

| 來源 | 建議篩選 | 目的 |
| --- | --- | --- |
| LINE 分析群（17 人） | 只選 2–3 位分析師固定 ID；視 Call 格式增加必要關鍵字 | 選取需要的 LINE／Telegram 群，Discord 文字頻道為選用 |
| Telegram 分析群 B | 若有人閒聊，也指定分析師 ID；Bot 必須可讀取其訊息 | 同一組目的，或獨立選擇 |
| Telegram 分析群 C（如有） | 個別核對作者與格式，避免直接套用不同群的 ID | 同一組目的，或獨立選擇 |

1. 停止轉送，載入聊天室，選來源及目的。
2. 展開「進階設定：指定發訊者、內容與時段」，選此來源，載入最近發訊者。
3. 選分析師加入白名單，也可逐行填固定 ID。LINE 使用 u 開頭的 MID；Telegram 使用數字使用者 ID。名稱只是辨認，不能拿暱稱當 ID。清單只列近期可讀訊息；缺少人員時等其發新訊息後重載或手動填入確認過的 ID。
4. 先用「填入 Call 訊關鍵字範例」，再依真實格式調整。範例為進場、買進、賣出、停損、停利、續抱、加碼、減碼、出場，符合任一個即可；這是文字包含，不是 AI 判讀。
5. 前綴可用 `[LINE Call] `、`[Telegram B] `。不改寫分析師的價格、時間或原文，也不會自動下單。
6. 用純模擬選擇每個來源，分別測試分析師 Call、路人 Call、分析師純寒暄，再保存、核對摘要。Telegram 圖片可切換媒體種類與大小；LINE 圖片未支援。模擬不發訊。

白名單會排除所有非指定人員；貼圖不在轉送範圍。分析師自己的「謝謝、你好」需搭配必要 Call 關鍵字才會排除。**不建議把「謝謝」直接設成排除字**：`進場 100，停損 95，謝謝` 仍是有效 Call，整則排除會漏訊。

若 Call 只寫股票代碼或價位，上述範本可能漏訊。「續抱」已加入範例，但其他寫法仍需核對。先以去識別化樣本做預覽，未確認格式前可先只用作者篩選，接受分析師偶爾寒暄。程式不會把略過內容送到公開診斷，修改條件也不會自動重算已處理的歷史。

## 3 個來源、4 個目的的配置範本

以下假設目的為 LINE 兩群、Telegram 兩群；實際可改成一群加三群等組合。先各來源一條純文字規則：

| 規則 | 來源 | 指定作者 | 目的 | 前綴 |
| --- | --- | --- | --- | --- |
| LINE Call | LINE 分析群 | 該群 2–3 位分析師固定 ID | LINE 目的 1、2；Telegram 目的 1、2 | `[LINE Call] ` |
| Telegram B Call | Telegram 分析群 B | 該群分析師，依實際需求選用 | 同上四群 | `[TG B Call] ` |
| Telegram C Call（如有） | 第三個來源 | 個別核對，不沿用其他群作者 | 同上四群或自行減少 | `[TG C Call] ` |

兩個來源共 8 組、三個來源共 12 組。原文與價位保留，各來源各發一次到每個目的，不把相同 Call 跨來源合併。v0.7.1 Mock 驗證三來源到四目的：有效 Call 與續抱共 24 次模擬平台接受，路人及純寒暄排除，重啟不增加已送次數；這不是實際平台的速度或送達保證。

文字先用作者白名單，內容條件須逐來源驗證。時段與回覆先維持關閉，避免讓 Call 延遲到稍後；新功能不會自動開啟。

## 少量圖片如何處理

LINE 來源圖片目前不會轉送；貼圖也不轉送。圖片中的 Call 無法靠文字關鍵字讀取，沒有 OCR，也不會生成圖片已送達的紀錄。主要文字轉送可先運作，但不能把這版當成完整圖片通道。

Telegram 來源可先只轉文字到四群；有說明文字的附件只轉符合條件的說明，圖片本身不會送達。若需要圖片送到 Telegram 目的，可將該來源拆為兩條規則：

- 文字規則：只選 LINE 目的，媒體關閉。
- Telegram 規則：只選 Telegram 目的，媒體開啟；這條同時處理文字及圖片。從原規則移出這些 Telegram 目的，避免重複啟用配對。

指定作者仍套用於圖片。沒有說明文字的圖片會被必要關鍵字擋下；若改成只依作者篩選，也會接受分析師自己的寒暄，需自行選擇取捨。受保護內容不轉送，超限或無法確認附件則暫停該配對。圖片轉到 LINE、LINE 圖片轉到兩平台，仍需後續媒體工程。

同一來源到同一目的只能有一組啟用配對；將同群的 2–3 位分析師放在同一白名單，不要複製多條同配對規則。不同來源即使文字相同仍分別送達，沒有跨來源內容去重；多位分析師轉貼相同 Call 可能產生多則訊息，這可保留來源證據。

Telegram 匿名管理員或頻道貼文可能只有代表聊天室的 `chat:ID`，無法分辨背後個人。不要把此 ID 當作某位分析師。Bot 也無法讀取未加入或未授權的私密群；沒有管理權限時需群主協助，不使用個人 Token 繞過。

Call 如果主要是 LINE 圖片，目前無法跨平台完整轉送；僅同一 Bot 的 Telegram → Telegram 可開啟圖片／檔案。時效性 Call 建議先不開時段，避免「保留」讓收件者收到過時訊息；如啟用，務必決定時段外要保留或略過。
