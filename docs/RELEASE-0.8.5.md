# v0.8.5：首次使用流程與規則管理改善

## 更新內容

- 分頁依操作順序排列為「1. 連結帳號 → 2. 設定規則 → 3. 啟動與狀態」，依設定進度選擇初始頁面。
- LINE 帳號連結後自動載入聊天室；選擇指定發訊者時自動載入人員，保留手動重新整理與失敗重試入口。
- 新增規則入口移至標題下方；啟動頁優先顯示開始／停止操作，返回規則改為次要操作。主要流程按鈕採淡綠樣式。
- 增加刪除規則與確認提示，避免誤刪；未保存規則在取消、替換編輯與離開頁面時提醒。
- 按鈕停用時說明原因；搜尋無結果顯示提示；新增規則依已有聊天室選平台，保存後清除搜尋，避免新規則被隱藏。
- 修正載入時誤顯示停止轉送提示；LINE 登入狀態與整體轉送狀態分開呈現。

## 下載與測試

[下載 ZIP](https://github.com/b40609/LinePort/releases/download/v0.8.5/LinePort-v0.8.5.zip) · [SHA-256](https://github.com/b40609/LinePort/releases/download/v0.8.5/SHA256SUMS.txt)

套件包含原始碼與啟動器，不含 Node.js、node_modules 或私人登入資料。

1. 安裝 Node.js，解壓至新目錄。在 PowerShell 執行 `cd yomi-probe`、`npm.cmd ci --ignore-scripts`、`npm.cmd start`。
2. 開啟 http://127.0.0.1:18765/，依「連結帳號 → 設定規則 → 啟動與狀態」操作。
3. 需要保留官方電腦版 LINE 時，可選 iPad QR 實驗登入；無需實體 iPad。仍須自行確認帳號與工作裝置能共存。
4. 保存並啟用規則後，按「開始轉送」；等待基準完成，再於來源發新文字，核對目的是否收到。首次啟動不補送歷史訊息。

舊版更新前先停止轉送與服務，私下備份完整資料目錄，再解壓新版至另一目錄；勿覆蓋私人登入資料。

## 驗證與限制

219 項自動化測試通過；本機檢查聊天室自動載入、規則新增／取消與啟動停用原因。本次發布前未重新執行真實訊息端對端轉送，請朋友依上述步驟測試。iPad 模式共存的既有驗證限單一帳號，其他帳號與裝置組合仍需個別驗收。
