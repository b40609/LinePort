# 疑難排解

先查看 http://127.0.0.1:18766/status 的 `phase`、`stage`。回報問題只需提供這些欄位、版本及錯誤計數，不要上傳登入目錄、PIN、群組內容或整份本機資料。

| 現象／階段 | 處理方式 |
| --- | --- |
| 手機沒有 PIN 輸入介面 | 確認主要手機已登入同一帳號且允許其他裝置登入；查看 LINE 的連動其他裝置提示。重新開啟手機 LINE，待原申請结束後再申請，不要並行反覆登入 |
| `data_permissions` | 檢查 LOCALAPPDATA 及 Windows 使用者存取權限；資料目錄不可含連結／junction。不要以公開共用資料夾取代，也不需用管理員強制啟動 |
| `resume` | 本機登入不存在或失效；先停止轉送，在登入頁完成恢復或重新授權，再啟動 |
| `groups` | 名稱包含 emoji，需完整複製；帳號必須加入兩個群組，來源目的不同且不能重名 |
| `route_identity` | 帳號或實際群組 ID 與原紀錄不符；停止並核對設定，不要刪紀錄硬闖 |
| `baseline` | 首次近期讀取或基準保存失敗；檢查網路、空間與權限，再停止及重啟 |
| `journal` | 紀錄無法寫入、損壞或末行不完整；停止並保留原檔供本機檢查。不可直接刪除，否則可能破壞去重依據 |
| `read` 且 failed | 連續讀取失敗達 5 次；確認網路及官方 LINE 狀態，再重啟 |
| `login_required` | 登入失效，先停止，再重新授權 |
| `send_uncertain` / `send` | 發送結果不明，整條轉送已停止；先人工查看目的是否收到，再重啟。該 ID 不會自動重送 |
| 18766 被舊版或其他程序占用 | 使用 stop-relay.ps1；若它拒絕操作，確認工作管理員命令列或原終端，不要一次結束全部 Node 程序 |
| 啟動器說另一條規則正在運作 | 先停止原規則，再重新選擇來源與目的 |
| running 但沒有收到文字 | 等基準完成後發「新」文字；確認最近 50 則、來源／目的名稱及 `polls` 是否增加。圖片、解密失敗、空文字不轉送 |
| 升級後還是舊頁面／舊行為 | 必須重啟相應 Node 程序；重新整理瀏覽器不足以套用伺服器更新 |

停止中的服務仍可提供狀態頁。頁面能打開，不代表轉送健康。LINE 出現限制、異常驗證或無法發訊時先停止工具，勿用不斷重試的方式處理。
